## ✨ 项目特色

- **全面系统**：覆盖数学基础、经典算法、深度学习、大模型、AIGC、智能体、具身智能与 AI for Science 的完整知识体系，并配有分阶段 / 分角色学习路线
- **权威可靠**：优先收录顶尖高校、研究机构与官方出品的资源，GitHub 项目综合 Star 数、活跃度与社区口碑筛选，链接均经过有效性校验
- **紧跟前沿**：持续追踪 Agent Skills、MCP / A2A 协议、AI 编程、上下文工程、推理模型等最新方向
- **中文友好**：每条资源均附中文简介与完整链接，同时收录大量优质中文书籍、课程与社区
- **开放共建**：任何人都可以参与贡献，详见 [贡献指南](CONTRIBUTING.md)

## 🧭 学习路线

> 不知道从哪里开始？按下面的路线循序渐进：先打牢数学与编程基础，再依次攻克机器学习、深度学习与大模型，最后进入智能体开发与工程化实践。每个阶段都直接链接到本清单中对应的资源分类

```mermaid
flowchart LR
    A["🧮 数学与编程"] --> B["📈 机器学习"] --> C["🧠 深度学习"] --> D["👀 CV · 📝 NLP · 🎧 语音 · 🎮 RL"]
    D --> E["💬 大模型与 AIGC"] --> F["🤖 RAG · Agents · MCP"] --> G["🚀 工程化与前沿"]
```

### 分阶段学习路线

| 阶段 | 学习目标 | 核心内容 | 推荐章节 |
|:--|:--|:--|:--|
| 阶段一 · 数学与编程基础 | 打牢线性代数、微积分、概率统计与 Python 编程基础 | 向量与矩阵运算、梯度与链式法则、概率分布与贝叶斯、NumPy / Pandas / Matplotlib 数据处理与可视化 | [🧮 AI 基础数学](docs/01-getting-started.md#-ai-基础数学) · [🐍 编程与数据科学](docs/01-getting-started.md#-编程与数据科学) |
| 阶段二 · 机器学习入门 | 理解监督学习与无监督学习的核心思想，能用 scikit-learn 完成完整建模流程 | 线性回归与逻辑回归、决策树与集成学习、SVM、聚类与降维、特征工程与模型评估 | [📈 机器学习](docs/02-core-technologies.md#-机器学习) · [📚 AI 经典书籍](docs/01-getting-started.md#-ai-经典书籍) · [🎓 课程与学习路线](docs/01-getting-started.md#-课程与学习路线) |
| 阶段三 · 深度学习核心 | 掌握神经网络原理与 PyTorch 框架，能独立训练与调优模型 | 反向传播、CNN、RNN / LSTM、注意力机制与 Transformer、正则化与优化器 | [🧠 深度学习](docs/02-core-technologies.md#-深度学习) · [🎓 课程与学习路线](docs/01-getting-started.md#-课程与学习路线) |

## 🤝 贡献指南

欢迎通过 Issue 或 Pull Request 推荐更多优质 AI 资源！提交前请阅读 [贡献指南](CONTRIBUTING.md)，核心要求如下：

- 资源清单按六大板块存放在 `docs/` 目录下，请将新资源添加到对应板块文件中最合适的分类
- 资源真实有效、质量过硬，优先使用官方链接；同一链接在全文中只收录一次
- 每条资源附 20～60 字的中文简介，「链接」列直接填写完整 URL，不使用图标或文字代替链接
- 提交前运行 `node scripts/build-site.mjs --check` 校验格式；新增分类后运行 `node scripts/build-site.mjs --toc` 更新目录与统计
